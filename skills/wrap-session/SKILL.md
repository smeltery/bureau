# Wrap Session

Review the conversation and verify the current state of the work you changed or delegated: uncommitted or unpushed changes, running jobs and CI, unfinished tasks, deferred decisions, and promised actions. Label unavailable checks as unchecked; do not report a live job as finished from an earlier message.

A loose end is something that still needs an action by an agent or a human. Report only those. For each one, propose one concrete next action, such as creating a Bureau task, recording a durable fact in the right project document or memory, writing a handoff brief, committing, pushing, deploying, or verifying a deployment. Ask before an action that still needs member approval.

Preserve outstanding member-only actions as persistent Bureau questions. Read the `questions` agent reference, list your own questions, and reuse or revise matching open items before creating any. Cancel only your own obsolete open questions using their current revision; refresh on a conflict and preserve answered receipts. Running jobs and work waiting on coworkers belong in the report, not in questions. Use masked credential requests for secrets.

Do not ask again for authorization already given. If closing this conversation leaves unanswered questions, tell the member that replies are tied to the original conversation; saved answers may need manual follow-up after a new session starts. Report ongoing work and its next step honestly instead of calling the session complete.

If you also want to tell the member something that needs no action, put it under the heading "Informative only, not actionable". Do not invent items for that heading to have something there.

If nothing remains, say so in one line and end the session.
